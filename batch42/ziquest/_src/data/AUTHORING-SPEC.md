## 每字目标 schema（chars 数组条目）

```json
{
  "ch": "晴",
  "src": "g1a",            // g1a=部编一上 | life=生活补充（已有，不动）
  "order": 23,             // 区域内教学序（已有，不动）
  "first": "1a-k9",        // 课标首见课（g1a 已有；life=null）
  "py": "qíng",            // 带调全拼（g1a 已有复核；life 必补）
  "pyKey": "qing",         // 无调拼音+同音序号（全表唯一；ü作v；同无调拼音按全表首见序加2,3…首见无后缀）
  "tone": 2,               // 声调 1-4（轻声 5）
  "words": [["晴天","qíng tiān"],["晴朗","qíng lǎng"]],   // 2-3词，词[0]必含本字
  "glyph": "太阳出来的好天气，日字旁加个青",               // ≤40字，讲给6岁孩子的字理（口语、具体、无术语）
  "parts": ["日","青"],    // 无争议部件拆分；独体字/有争议=null
  "family": "qing",        // 声旁家族键（同声旁成族≥2字才填；独体/无族=null）
  "freq": 4,               // 常用度 1(最常用)~5(较生)
  "distract": [["睛","形近"],["情","同声旁"],["清","同声旁"]]  // 恰3个；格式[字,理由]
}
```

## 教研铁律（违反=返工）

1. **多音字一致性**（历史事故位）：`words[0]` 读音必须与 `py` 一致。
   例：「长」py=cháng → words[0]=["长江","cháng jiāng"]（禁"长大 zhǎng"）；
   「乐」py=yuè（音乐）→ words[0]=["音乐","yīn yuè"]；「发」py=fà？——用常用音 fā 头发/发芽选教学主音，全表一致。
2. **words[0] 必含本字**（挖空题与语音文案依赖：`zi_ch` 式文案="字，首词的字"）。
   词为 2-4 字常用词/儿童口语词；禁生僻词、禁书面文言词。
3. **glyph 字理**：≤40 字；先说"这是什么"再说"怎么记"；
   象形字讲演变（"山的形状，三座山峰"）；会意讲组合（"日月同天就是明"）；
   形声讲偏旁（"吃饭的吃，口字旁加乞，用嘴吃"）；讲不出通俗字理就讲用法语境（"洗手的水，跟水有关"）。
   禁术语（禁"形声字/会意字/部首"等词出现在文案里——说人话）。
4. **distract 恰 3 个**：优先形近（日/目、鸟/乌）→ 同声旁（清晴情请）→ 同类近义。
   干扰字允许表外字（仅作选项显示）；**禁与目标字构成字形包含**（如干扰"苗"对目标"田"可以，干扰"雷"对目标"雨"不行——雨在雷里）；
   3 个互不重复、均 ≠ 本字。理由只允许："形近"|"同声旁"|"同类"。
5. **parts 安全拆分**：仅左右/上下/包围结构且部件成字无争议才拆
   （晴=[日,青]、明=[日,月]、想=[相,心] 或 null、亮=null）；
   独体字（天/大/上）= null；拆出的部件必须是 CJK 基本区常用字（禁"⺮/灬"等不成字部件单独出现）。
6. **pyKey 全表唯一**：先无调拼音（ü→v），若与他字同音（如 石 shí / 十 shí / 时 shí），
   按「本文件内出现顺序」第二个及以后加序号：shi, shi2, shi3。**跨文件序号以 R1→R7、区域内 order 序为全局序**（你只处理你组内文件时，同文件内冲突先这样排，跨文件冲突留主线机扫统一重排——你需在报告里列出你组内的同音字组）。
7. **freq 参考档**：1=的了我是天地上（最高频虚词/基本名词）；2=日月水火妈爸；3=晴雾季；4=较书面；5=生僻。
   拿不准给 3。
8. 生活字（src=life）必须补 py/tone/words/glyph/distract/parts/freq（first=null 保持）。
9. g1a 字已有 py（来自课标数据）——仅复核不改（发现明显错误记录到报告，不擅改）；
   words0 字段是课标参考首词，可采纳可换更好的，采纳时补注音。
