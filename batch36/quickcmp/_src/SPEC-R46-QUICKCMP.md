## §R3 生成规则与数量域（先验写前验算）

### rnd 消耗序（pycheck 复刻真值源；seed=mulberry32(flat*7919+887)）
```
genLevel(flat):
  静态关 dch=diffOfCh(ch)（0 rnd）；生成关 dch=ri(rnd,1,4)（1 rnd）
  每题 buildQuiz(dch, rnd)（消耗按 dch，见下）→ scatter(nL)+scatter(nR)
buildQuiz 消耗：
  dch1: ri(POOL_SUB) 1 rnd
  dch2: 掷 t=rnd()（<0.3 等数/否则非等）+ ri(池) 1 rnd = 恒 2 rnd
  dch3: ri(POOL_R3) 1 rnd
  dch4: ri(POOL_DUAL) 1 rnd（镜像在池内，无独立掷侧）
scatter(n, rnd): n≤12 → shuffled(12格) 11 rnd + n×2 rnd（抖动 xy 各 1）；n≥13 → shuffled(20格) 19 rnd + n×2 rnd
```
