# kids-games · 儿童离线小游戏库（120 款）

面向 5-8 岁儿童的离线 HTML5 小游戏合集，小兔子 IP 贯穿全部游戏。**零依赖、零网络请求、零账号**——每个游戏是一个自包含的单文件 HTML，语音以 base64 内嵌，下载后用任意现代浏览器打开即玩，完全离线。

## 玩法入口

打开根目录 `index.html`（主入口，120 款游戏总目录），或各 `batchN/index.html` 段入口。适合平板 / 触屏 / 鼠标操作。

## 内容结构

- **三个年龄段 × 各 40 款**：5-6 岁（降坡起步）/ 6-7 岁 / 7-8 岁（学段标称难度）
- **覆盖面**：数学思维（分数/竖式/钱币/等分/比大小/方位/图表/逻辑推理）、语言识字（汉语拼音识字/古诗/成语/英语单词/句子排序）、科学常识（昆虫/电路/齿轮/混色/日历）、社会情感（情绪认知/感恩表达/轮流分享/冷静策略/安慰选择）、音乐节奏（听音辨数/音高/和弦/打节奏）等
- **难度改造期（Task#45）**：全量审计后对 86 款（红 40 + 黄 46）逐款加深到学段标称难度——撤支架、加近对干扰、上探认知负荷；每款经独立复验 + 反方审查 + 无头试玩三轮门禁

## 技术形态

- 纯 vanilla JS / CSS / SVG，无框架无构建产物依赖；每款 = `index.html`（交付物）+ `_src/`（构建源：game-main / game-core / game-data / game-verify / build.py / SPEC 规格书）
- 语音全部预合成（edge-tts 晓晓 + AnaNeural，5517 条 clip），构建时以 base64 内嵌进单文件——离线可听，消灭系统 TTS 机械音
- `design/core.js` 为共享引擎层（关卡日历/星级/存档/救援提示/语音队列）；`voice/` 为合成流水线（gen_clips.py + clips 资产 + manifest）
- 质量：每款配 verify 自测页、_selftest、gate 三门禁与谱对拍（mulberry32 种子序列 Python 同构复算），全部 playwright 无头验证
