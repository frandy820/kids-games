# 儿童游戏教学观察报告（batch2 三款 · 模拟 5 岁半女孩 · 教学者视角）

> 证据附件：`batch2/shots/t2_{memory,tangram,color}_obs.json`（结构化数据）、`batch2/t2_observe.py`（可复现驱动脚本）、`batch2/shots/` 下 19 张 t2_* 截图。
> 方法：每款独立 headless Chromium 全新实例 + 临时 profile，file:// 直开，全新存档；按人设操作（每步 2-5 秒延迟、放偏/翻错/狂点、卡住不动 20-26 秒）；全部判断基于 DOM 查询与 MEM/TAN/COL 钩子、getBoundingClientRect 几何断言、voice/sfx 调用记录；三款全程 0 个 JS 错误。视口 800×1180（iPad 竖屏）。

## 一、记忆翻牌（memory）——表现最好的一款

**教学关观察（1-0，2×3=3 对）**：看-帮-独三段自足。开屏自动演示翻一对（牌 0/1 变 gone）；演示中途她乱点牌 2，被安全吞掉（tapCard 的 state.demo 拦截，牌 2 保持 down，无副作用）。进入"帮"后幽灵手指指向牌 0（`#ghost.show`，over=0，牌 0 带 pulse 类）；她翻开牌 0 后 550ms 手指自动转向配对牌 1（over=1）——"手指会跟着教"这一点她跟得上。首次配对成功即转 solo 放手（tut=solo，托盘 mini 点亮 1）。

**试玩观察**：
- 失误反馈可理解：不匹配两张停 900ms（.miss 蓝灰描边）再盖回；判定锁定期内她连点第三张牌两次，全部被吞（state 保持 down）——防手滑，但吞得无声（见 P2-7）。
- 防挫败救援真实有效：1-1 连续三次翻错（三对全翻过又盖回），第 3 次盖回的瞬间幽灵手指自动出现指向已知配对（ghost over=0、pulse=[0]）+ 语音 mem_hint「找到一样的两张」（vlog 实录）；跟着手指翻牌、配对成功。
- 卡住 20 秒：只有语音提示（mem_hint 触发），无任何视觉帮扶（ghost_show=false）。
- 星级宽容：1-2（4 对）全程靠运气翻、8 次失误仍拿 2 星，永不 0 星；存档正常（1-0 3★/1-1 3★/1-2 2★）。
- 过关演出（2.3s）期间乱点三处：全被覆盖层吞掉，celebrate 完整播完自动进下一关。

**DOM 证据（节选）**：`t=57.7s 1-1三连失误→支架 {misses:3, ghost:{show:true,over:0,pulse:[0]}, voice_mem_hint:[{key:"mem_hint"}]}`；`t=84.8s 卡住21秒 {voice:[mem_hint], ghost_show:false}`；`t=159.4s 1-2过关 {stars:2, misses:8}`。

## 二、七巧板（tangram）——核心玩法有硬伤，教学后仍需陪伴

**教学关观察（1-0 mountain2 两块）**：看=自动把块 0 吸进目标；中途点块 1 被吞（r/x/y 不变）✓。帮=幽灵手指指向块 0，但**块的 pulse 高亮从未出现**（class 恒为 "piece"；同代码在 memory 上 pulse 正常、手动加 pulse 类也能正常出动画——推断教学重发关时 pointGhost 与 buildBoard 重建 DOM 有竞态）。**"看"只演示了"放"，没有演示"点一下转 45°"这个过关必需手势**（推断：孩子只能靠语音或试错发现）。

**试玩观察**：
- 放偏 90px 松手：块停在落点不回弹、不锁死（wrongflash 摆动一下），可随时重拿——安全 ✓；但幽灵手指不跟随块移动，仍指空了的旧托盘位（over_piece=null）。
- **P1 甩飞**：把形状中心对准轮廓松手（不吸附，角度不对），然后按习惯点块的"中间"——**点转是绕块的锚点顶点（非中心/质心）旋转**，每点一下块绕远处顶点大幅甩动：bbox [36,102,523,318]→第 1 下 [-133,79]→第 2 下 [-170,102]，一半以上甩出屏幕左缘；探针实测此后点块视觉中心（已在屏外 x=-10）**6 连点全部落空（elementFromPoint=null）**。块不锁死、理论上可抓回，但 5 岁孩子点不到就只会放弃。教师拉回中央后连点 4 下才到等价角，途中第 3 下 bbox y=-46 又甩出上缘。
- **P1 死代码**：闲置看护里 20s 语音分支先触发并把 idle 计时清零，**25s 的轮廓高亮（hintpulse）永远达不到**——两次 26 秒实测 `hintpulse:[]`，只有 tan_hint 语音。spec 承诺的"块闲置 25 秒高亮目标轮廓"实际不存在。
- 误抓已就位块：拿起即解除就位（防误拆无锁），且进度盘不熄灭（prog_before=1/after=1，renderProg 未调用）——她拆了已放好的块自己看不出来。
- 好的一面：宽容度高，转对角度后偏 30px、45px 松手三次全部吸附成功；狂点 6 下只是块转圈（r 序列 0→5），无惩罚；演出期间乱点被吞；星级保底 1 星（多余操作 12 次仍 1 星）。

**DOM 证据（节选）**：`硬放 {placed:false, cts:4, anchor:[0,1], bbox:[36,102,523,318]}`→`tap1 bbox[-133,79,595,595]`→`tap2 bbox[-170,102,318,523]`；探针 `tap3-8 hit null, r 停在 2`；`26秒后帮扶 {slot_hint:{hintpulse:[]}, voice:[tan_hint]} ×2 关`；`误抓已就位块0 {placed0:false, prog_before:1, prog_after:1}`。

## 三、涂色本（color）——零挫败设计到位，最适合放手

**教学关观察（1-0 花，10 区域）**：全新存档直接进教学关（无首页绕路）✓。看阶段乱点区域 0/1：**不被吞，立即被填色**（color=0）——教学演示照常走完，"帮"随后正常接管（finger_go=true、色块 pulse）→ 无破坏但演示会被抢跑（低害）。帮=手指指空白区域+当前色高亮；填满 2 个区域教学即收手（finger_go=false）✓。瑕疵：收手后 pulse 高亮残留在色块 0 上，并跨关带进 1-1（stopTut 只清 .sel 的 pulse）。

**试玩观察**：
- 无对错：想要粉色误点成邻近的紫色（色块 7/8 相邻，64px、两行排布）——没有任何后果，覆盖重填零惩罚，完美契合"颜色命名不稳固"的孩子。
- 小区域命中外扩生效：1-2 图 4 个 hitaid 透明圈，点圈中心正确填到目标区域。
- 提前点"完成"：30% 点击→toast「还有空白哦」+语音，1.9s 自动消失，继续涂完全不受影响 ✓。但 40-60% 区间**再点一次=1 星直接过关**：实测 50% 时二连点把 1-1 以 1 星收进存档（符合 spec"提示后再点=1 星"，但 5 岁双击习惯容易意外提前结束）。
- 误点主页再进：整关填色进度全丢（filled 2→0）。
- 卡住 20 秒有语音提示；撤销生效（filled 1→0）；涂满 800ms 自动 3 星"真棒！"（探针复核 stars=3）；演出期间点色块被吞（sel 0→0）✓。

**DOM 证据（节选）**：`看阶段点区域0 {region0_color:0}`；`演示走完 {finger_go:true, swatch_pulse:true, n_filled:3}`；`收手 {finger_go:false, pulse_on:"0"}`；`50%再点完成→{stars:1, filled_ratio:0.5} 存档1-1:1★`；`误点主页 {filled_before_home:2, filled_after_reenter:0}`。

## 五、终评：教完一次后能否放手独玩

- **记忆翻牌：能。** 教学-手指引导-三连失误支架-星级宽容全链路自足，不依赖识字，图形配对正好落在她 3-4 项记忆容量内（3-4 对的关）；4×5 大阵会退化为纯运气但永不挫败。
- **涂色本：能。** 无对错、无倒计时、撤销+温和提示+命中外扩齐全，邻近色混淆零代价；唯一要叮嘱的是"别点小房子（主页）"。完成按钮的双击问题只影响星星不影响体验。
- **七巧板：勉强（第一周需成人在旁）。** 玩法本身零惩罚且吸附宽容，但"点转绕锚点甩飞"+"视觉救援实际缺失"+"旋转手势没教"三件事叠加，孩子卡住时真实可用的只有 20 秒一句语音；教会她"先在托盘点转、再拖过去、抓块时抓边角"的策略后可降级为能。修掉两个 P1 后可到"能"。
