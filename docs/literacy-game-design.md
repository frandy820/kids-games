# 识字小课堂（G121 zilearn）体验设计（literacy-game-design）

> 阶段2 产出的真值源。先诊断后设计后实施；诊断报告（agent 真实完整玩）到达后补「诊断确认」段；

## 一、现状结构（代码事实）

每关 5 题位固定序：qi0 字理亮相（音形义，0 判定）→ qi1 听音找字（音→形，half×2）→ qi2 词挖空/句子找生字（义境→形）→ qi3 组词搭配（形→词）→ qi4 关末小测（half→right）→ celebrate → 章末/日末。

- 150 字/20 静态关/生成关（GEN_POOL 50 渐进+1/3/7 复习加权）；日限速 2/3/4/6 关（首日起）；
- 教学三段（看→操作→独，仅 flat0 首开）；救援双锚 14s 方向级/30s 答案级（keepIdle）；
- 防泄露：视觉题面期不播目标字音（键账断言）；core pointerdown 音频解锁+播放静默兜底；
- 内容一致性：150 字 pyFull↔words[0] 读音机械扫描 0 矛盾（2026-09-25 本轮）；拼音/组词/句子/字理上轮人工全核（REVIEW-r1）。

## 二、保留（不动的部分——它们是有效的）

## 三、诊断确认（zilearn-diagnosis.md，9 场景实测+52 截图，2026-09-25）

- ✅ D1 必做：「通关结算只见星星不见学会的字」——孩子侧成就零表达（家长面板账目准确但给孩子看的缺席）。
- ✅ D2 必做且升级：「连错 3 次只有 1 次『不对哦』选项原样」（flat≥3 10s 节流实证）——最大教学浪费点；诊断建议阶梯式：错 2 重播字音组词例 / 错 3 摘干扰。
- ✅ D3 部分成立：静音听音题 30s 才 breathe（对幼儿=没有）；播放失败**完全静默**（家长无从发现）→ F7 视觉提示必做；breatble 提前由 F2 阶梯覆盖（错 2 即干预），30s 兜底保留。
- ✅ 新发现（超出预判）：①word 题无读音支架（题面不读词）②match 题可"找包含字"必胜（假答）③「读一读选出生字」副提示只有文字无语音 ④兔子 flat3+ 静默 ⑤义线 83% 断裂（124 plainmode 字无字理，glyphmode 为死代码——上轮 M4 只藏了气泡未补内容）。
- 教学流/确认链/句子题/防泄露/干扰体系/日历限速=真资产（诊断 I 节），全部保留。
