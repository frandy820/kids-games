# 家长试玩记录卡（5 款推荐款）

> 配套 [final-improvement-report.md](final-improvement-report.md) 第七节推荐清单。
> 用途：首次真机试玩前打印/照抄使用。每款一张卡，试玩一次（约 10-15 分钟）填一张。
> 卡片只列**可观察的行为和现象**，不预填任何结论——结论由你记录的实际观察产生。

## 使用前须知（三件）

1. **进游戏**：双击打开 `index.html`（总入口）→ 按年龄段分区 → 点游戏卡片。也可直接双击各款 `batchNN/<游戏名>/index.html`。
2. **返回方式**：游戏内**没有**「返回目录」按钮（全库现状），退出/换款用浏览器返回键（◀）或直接关标签页。游戏内也**没有暂停按钮**，中途离开=直接返回。
3. **语音**：每款开场有语音读题。若无声，先检查：设备音量 → 游戏内声音开关（通常在角落）→ 换浏览器（推荐 Edge/Chrome）。三步都排除仍无声才算可疑问题。

通用记录法：记**原话**和**操作**（点了什么、停在哪一步、看了多久），不记家长自己的解读。例：「第 3 关听完题没动，约 8 秒，说『我不知道哪个』」——这是好记录；「他觉得太难」——这是解读，尽量少写。

## 卡 1：hidecup 躲猫猫杯子（5-6 岁 · 视觉追踪）

**入口**：`batch34/hidecup/index.html`（总入口 → 5-6 岁区）

**首次试玩观察 3 个行为**
1. 换位动画阶段：孩子的眼睛是否跟着目标杯子移动（还是只盯着中心/动物）？连续换位 3 次以上时是否跟丢？
2. 第二章起的「两步题」（两只动物都要找）：第一遍是否只答了一只？答完一只后能否自己发现还要找第二只？
3. 最难的闪现关卡（先短暂展示、盖住后再作答）：闪现结束后，孩子是马上点还是等重看？用了几次「再看一遍」？

**家长记录**
- 孩子指认杯子时说的原话（如「在这」「是这个吧」）
- 哪一关第一次犹豫/第一次答错：记关号+当时杯子数量+换位次数（屏幕上可见）
- 主动要求「再来一次」还是想换游戏：记录时间和当时的关

**Bug / 体验问题判别**
- 可能是 Bug：点杯子后完全没反应（无动画无声音）且连续多关如此；换位动画明显卡顿或杯子错位；语音与画面动物对不上。
- 大概率是体验问题（需更多样本）：跟丢换位、两步题漏答一只、闪现关要求重看——这些是难度设计范畴，单次观察不下结论，记下即可。

## 卡 2：soundcount 听音数数（5-6 岁 · 听觉计数）

**入口**：`batch33/soundcount/index.html`（总入口 → 5-6 岁区）

**首次试玩观察 3 个行为**
1. 纯听题（画面无数量提示）作答后问一句「你怎么数的」——孩子是心里跟着数、手指点节奏、还是听完凭感觉猜？（记原话）
2. 数字较大时（6 声以上）是否要求重听？重听几次后作答？
3. 最陡的「两种声音」关卡（如鸭子叫和铃铛交替）：是分开数还是混着数？第一次接触这型题时的反应（停下/乱点/要求帮助）。

**家长记录**
- 每题实际听到的声音次数（家长自己默数）+ 孩子答的数字——答错时这对数字最有价值
- 孩子是否用嘴跟着数出声（记录从第几题开始/停止）
- 音量环境：房间安静/有背景声（听觉题对环境敏感，必记）

**Bug / 体验问题判别**
- 可能是 Bug：点「重听」没有任何声音播放（且其他游戏语音正常）；数字卡点了没选中效果；答对却判错（此时记下你默数的次数+孩子的答案）。
- 大概率是体验问题：猜答案、要求多次重听、大数字错 1-2 次——听觉计数对 5-6 岁本就是难点，多玩几次再判断。

## 卡 3：calendar 日历小星（6-7 岁 · 推理）

**入口**：`batch26/calendar/index.html`（总入口 → 6-7 岁区）

**首次试玩观察 3 个行为**
1. 「多步跳」题（如 11 月再过 2 个月是几月，需跨年）：孩子是扳手指逐月数、直接说、还是停住？答错的题记下原题月份和跳数。
2. 「昨天/今天/明天谁在前」类环序题：听完题到作答的间隔时长（大概几秒）；是否要求重听题目。
3. 长语音读题（多段连播）时：孩子是全程听完再动，还是中途就开始点？中途点被忽略时孩子的反应。

**家长记录**
- 错题原样：月份/星期/跳数（如「周五+3 天」，孩子答了什么）
- 孩子自己嘟囔的推理过程原话（这个年龄段常自言自语，是最真实的理解证据）
- 哪一章开始速度明显变慢或要求离开

**Bug / 体验问题判别**
- 可能是 Bug：屏幕题面文字与语音读的不一致；按正确推理答对却判错（记原题+答案，此为最高优先级记录项）；点选项无反应。
- 大概率是体验问题：跨年多步跳错、环序方向（前/后）混——这是 6-7 岁推理款的正常爬坡点，错不等于不适龄。

## 卡 4：cbx 冷静工具箱（6-7 岁 · 情感选择）

**入口**：`batch40/cbx/index.html`（总入口 → 6-7 岁区）

**首次试玩观察 3 个行为**
1. 每题三张卡（一张最佳、一张「也好但不最好」、一张不该选的）：孩子选完后问一句「为什么选这个」——记录能否说出理由（原话，不纠正不提示）。
2. 选了「也好但不最佳」的卡时游戏给的反馈：孩子看完/听完反馈后，下一题的选择有没有变化（仍随手选 vs 开始对比）。
3. 选到明显不该选的卡（如生气时摔东西）：孩子当时的表情/反应——觉得好玩故意再选一次，还是认真看完反馈？

**家长记录**
- 每题的情境（一句话）+孩子选的策略名 + 孩子给的理由原话
- 故意选「坏卡」玩闹的次数（若有）——这是正常探索，与不懂区分开
- 孩子是否把游戏里的策略词带到游戏外（如事后说「我可以深呼吸」）——记录时间点

**Bug / 体验问题判别**
- 可能是 Bug：选了明显正确的策略却判错（记情境+所选卡文字）；卡片文字显示不全/乱码；反馈语音与所选卡内容对不上。
- 大概率是体验问题：理由说不清、好坏卡犹豫——价值判断表达本来就是该款训练目标，首玩说不清属预期。

## 卡 5：robotdance 机器人学舞（7-8 岁 · 序列记忆）

**入口**：`batch32/robotdance/index.html`（总入口 → 7-8 岁区）

**首次试玩观察 3 个行为**
1. 观看演示阶段（机器人跳舞）：孩子是安静看完还是中途想点（被忽略时的反应）？长序列（7-8 步）时是否跟着做动作/念步骤？
2. 「改错题」（序列里有一步错了，找出并改正）：孩子是先完整看一遍再比对，还是看到一步就点？找错用了多久？
3. 题与题之间的等待（上题庆祝+本题演示）：孩子是否表现出不耐烦（乱点/催促/离开座位）？大约第几关开始出现？

**家长记录**
- 能复现的最长步数（第几关、几步开始复现失败）
- 改错题：找错用的时间+找对了吗+改的时候改成了什么
- 等待期不耐烦的表现原话（「快点」「怎么还不开始」）和出现频率

**Bug / 体验问题判别**
- 可能是 Bug：非演示期点击舞步无任何反应；自己复现的序列与演示完全一致却判错（尽力记下步骤顺序，此为关键记录）；改错题改正后不进入下一题。
- 大概率是体验问题：长序列记不全、题间等待觉得慢——等待节奏是已知的设计权衡项（演出完整性优先），多玩两次看是否适应再下结论。

## 记录回收方式

试玩后把填好的卡拍照或文字发给开发侧（本仓库维护者）。每条观察会按四分类处理：
**A** 可复现程序问题（附你的复现步骤）→ 修复；**B** 不理解规则 → 文案/教学改进；**C** 难度不合适 → 调参；**D** 个体偏好 → 备案不改。
没有证据支撑的现象只登记不改动（known-issues.md）。
