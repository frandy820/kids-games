# 手工测试清单（人工验收用）

> 定位：机器已覆盖的（五门禁+审查+试玩，见 ledger.md §2）此处不重复；本清单只测**机器测不了的面**——
> 真实听感、观感、儿童反应、跨设备手感。抽样执行，不求全量。

## 一、测试前准备
- [ ] 断网（或开飞行模式）后打开游戏——验证离线可玩（本项目零网络请求，断网应无任何功能损失）
- [ ] 设备任选：平板（触屏）/ 笔记本（鼠标）/ 手机（窄屏）各至少过一轮通用清单
- [ ] 音量：首轮开声音听语音自然度（预合成 clip 应为自然人声，无系统 TTS 机械音）；第二轮关声音验证纯视觉可玩

## 二、通用清单（每款 3-5 分钟，适用全部 120 款）
| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 从主入口 index.html 进入该款 | 卡片可点、正确跳到该游戏 |
| 2 | 首屏 3 秒内理解 | 孩子能说出"要干什么"（图形/语音解释，无需读长文字） |
| 3 | 教学链 | 首次进入有小兔子示范，看完/可跳过后进入第一关 |
| 4 | 核心玩法一轮 | 答对：有具体正向反馈；答错：无红叉/嘲讽，有方向性提示 |
| 5 | 救援提示 | 故意静置 15-30 秒，出现温和提示（14s 方向级/30s 答案级） |
| 6 | 章末/日末结算 | 完成一章有成果展示（星星/徽章），非"再来一局"强刺激 |
| 7 | 退出与重开 | 浏览器返回键/主入口按钮可退出；重进后进度保留（localStorage） |
| 8 | 连玩刹车 | 连续玩多关后出现休息提醒（温和、不阻断） |

## 三、儿童安全红线（全款扫描，发现任一即记 FAIL）
- [ ] 无广告、无外链跳转、无登录、无付费入口、无社交分享
- [ ] 无倒计时恐吓、失败羞辱、强闪烁
- [ ] 家长面板入口非儿童易入（找到入口并确认形态）
- [ ] 断网状态下打开 F12 → Network 面板：零外部请求

## 四、抽样建议（120 款不必全测）
- 每年龄段抽 4-5 款 + 自己孩子常玩的款优先
- 本轮已深度改造的 86 款优先于维持现状款
- 首批推荐试玩（覆盖三段+四种玩法型）：
  | 款 | 段 | 玩法型 | 观察重点 |
  |----|----|--------|----------|
  | hidecup 躲猫猫杯子 | 5-6 | 视觉追踪 | 双动物两步题是否卡壳；提速档跟得上吗 |
  | soundcount 听音数数 | 5-6 | 听觉计数 | 纯听（无视觉锚）时会不会依赖猜 |
  | calendar 日历小博士 | 6-7 | 推理 | 多步跳题（+2 月跨年）理解度 |
  | cbx 冷静工具箱 | 6-7 | 情感选择 | fair 次优卡（好但不最佳）的选择理由能否说出 |
  | robotdance 机器人学舞 | 7-8 | 序列记忆 | fix 改错题（改一步）的观察-比对过程 |
