## §1 coder2 循环指令（循环块编程；点指令卡编排款，不灰化）

**玩法**：每题=网格地图（6×6 内）+小兔起点+胡萝卜目标（+可选障碍格）+指令卡池（前进/左转/右转/重复 2 次□/重复 3 次□）。点指令卡入程序序列（底部序列条），点序列内指令=退回。点「运行」：小兔依序执行（逐格动画），到达目标=celebrate+下一题；未到/撞障碍=小兔回起点零惩罚可改程序。
- 题型（4 章，GEN 确定性）：ch1 纯序列 3-4 步直角路径（无循环）；ch2 含 1 个重复块（重复 2 次子序列 ≤2 指令）；ch3 含 1 个重复块（重复 3 次）+障碍；ch4 生成关（嵌套不引入——重复块内子序列含前进+转向，路径方形/之字形）
- 星级：错次口径（运行未到目标=1 错；退回不计）；救援=目标格 breathe+首条应放指令卡 pulse
- 教学：watch=演示看地图→点指令→运行到达；帮/独；`__cd2DemoR`
- 钩子：`CD2 = { get currentLevel, get quiz(){ W,H,start[x,y,dir],goal[x,y],walls[](障碍格),pool[](指令卡{t:'f'|'l'|'r'|'rep2'|'rep3'}),prog[](已编排指令或 null),runState,step,miss }, tapPool(i), tapProg(i), run(), autoSolve() }`
- 语音：cd2_tut_watch'看！排好指令走一走'/cd2_tut_turn'你来排一排'/cd2_hint'想一想小兔怎么走'/cd2_right'到达啦，真厉害'/cd2_wrong'再看看路线改一改'/cd2_run'出发喽'；指令词=TTS 兜底豁免（动态序列）；障碍提示 cd2_wall'前面走不通啦'

## §2 stack 搭高楼（堆叠平衡；点放置款，不灰化）

**玩法**：每题=地基线+待放楼层块序列（每块有宽度 2-4 格与颜色）+当前块在屏幕上方左右移动（往返）或静止由孩子点选放置列。**点格子列放置**：块落下堆叠在最高层上。全部楼层放完且塔不倒=celebrate+下一题；某层偏移超平衡域=塔倒动画+从倒塌层重搭零惩罚。
- 平衡模型（简化确定性，§0.38）：每层块的放置偏移=该块中心相对下层块中心的水平偏移；|偏移| > 下层块半宽-当前块半宽+安全裕度 → 不稳定倒塌（越叠越险：塔整体偏移累积判定=各层偏移矢量叠加，总偏移超出地基半宽则倒）
- 题型（4 章）：ch1 单列堆 3-4 块（对齐宽容）；ch2 块宽渐变（下宽上窄/下窄上宽，偏移域不同）；ch3 含风摆块（必须放到反向偏移位抵消——预判启蒙）；ch4 生成关（5-6 块+两处风摆，稳定解不唯一但存在性保证）
- 星级：错次口径（倒塌一次=1 错）；救援=安全放置列 breathe
- 教学：watch=演示看塔基→点列放置→对齐不倒；帮/独；`__stDemoR`
- 钩子：`ST = { get currentLevel, get quiz(){ cols(可放列数),floors[](待放块{w,color}序列),placed[](已放{col,off}),wind(当前风偏或 0),phase,step,miss }, tapCol(c), autoSolve() }`
- 语音：st_tut_watch'看！把高楼搭起来'/st_tut_turn'你来搭一搭'/st_hint'对整齐就不倒啦'/st_right'搭好啦，真稳'/st_wrong'歪了歪了，再来一次'/st_wind'风来了，放另一边'；层数 TTS 兜底（st_n_ 数词副本不建——b13 起家族数词 clip 仅在题面句使用时建）

## §3 bounce 弹球角度（反弹预判；点洞/方向卡款，不灰化）

**玩法**：每题=弹球台面板（SVG，6×5 格当量）+球起点+发射方向箭头（2-3 个候选方向卡）+墙（边界恒在+内部障碍墙段）+洞（2-3 个，含 1 正确）。孩子点方向卡→球沿直线飞出遇墙反弹（入射角=反射角，动画）→入洞=celebrate+下一题；入错洞/出界=零惩罚可重点。
- 题型（4 章）：ch1 单次反弹入洞（1 面内墙）；ch2 两次反弹；ch3 三次反弹+斜墙（45° 角镜面，翻转轴向分解）；ch4 生成关（3 洞 3 方向，恰 1 方向入正确洞）
- 星级：错次口径（入错洞/出界=1 错）；救援=正确方向卡 breathe+首段轨迹虚线闪（**梯度脚手架（试玩 P1-2 定案）：错 1 次即闪首段虚线（方向级线索）；正确卡 breathe 仍 miss≥2 才出（答案级提示不提前）；进错洞=洞上打 ✗+「进错洞啦」TTS 语义化反馈**）
- 教学：watch=演示看球弹一弹→指方向→点对；帮/独；`__bcDemoR`
- 钩子：`BC = { get currentLevel, get quiz(){ W,H,ball[x,y],holes[](洞{x,y}),walls[](墙段[x1,y1,x2,y2]),dirs(候选方向数组[dx,dy]),answer,step,miss }, tapDir(i), autoSolve() }`
- 语音：bc_tut_watch'看！小球弹弹弹'/bc_tut_turn'你猜它进哪个洞'/bc_hint'想想球会怎么弹'/bc_right'进洞啦，猜对了'/bc_wrong'再想想弹的方向'；无词 clip
