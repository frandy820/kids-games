## §1 cipher 密码破译（映射表解码；点卡排序款，不灰化）

**玩法**：每题=密码表（4-6 对「符号↔数字或字」卡片，图符号 SVG 自绘）+密文序列（2-5 符号；ch2 词 2-3——审查 m6 措辞精度）+候选答案字卡池。孩子查表逐符解码（密文下方可点开对应映射闪联），点选/排布解码结果。答对=celebrate+下一题；答错=零惩罚可重选。
- 题型（4 章，GEN 确定性）：ch1 符号→数字（密文解码=数字串，选正确数字卡序）；ch2 符号→字（解码=词语如「太阳」）；ch3 缺表推理（表缺 1-2 对，由已解例推：同符号同像——干扰项制造歧义则该题非法 §0.40）；ch4 生成关（5-6 对表+4-5 符密文+干扰卡 2-3）
- 星级：错次口径（答错=1 错）；救援=密码表对应行 pulse（方向级恒给）+正确首卡 breathe（**答案级：miss≥2 才出**——审查 m1 统一 b18 梯度定案）
- 教学：watch=演示查表→解码→选卡；帮/独；`__ciDemoR`
- 钩子：`CI = { get currentLevel, get quiz(){ W?, table[](符号↔像对{sym,img}), cipher[](密文符号序), answer(正确解码序列), opts[](候选卡), step, miss }, tapOpt(i), autoSolve() }`
- 语音：ci_tut_watch'看！破译小密码'/ci_tut_turn'你来破一破'/ci_hint'查查密码表'/ci_right'破译成功，真聪明'/ci_wrong'再对对密码表'；符号名/数字词=TTS 兜底豁免

## §2 gomoku4 四子棋（vs 兔子 AI；点格落子款，不灰化）

**玩法**：每题=一局棋（5×5 棋盘，孩子执胡萝卜色先行或后行交替，兔子 AI 应手）。点空格落子；横/竖/斜四连即胜。胜=celebrate+下一题；负=零惩罚「再来一局」（局数推进口径：胜或平=过题，负=重下不推进可换先手）；平局（满盘无四连）=过题。
- 题型（4 章）：ch1 4×4 棋盘先手（AI 仅堵不攻——几乎必胜建立信心）；ch2 5×5 先手（AI 会一步制胜）；ch3 5×5 后手（AI 先手开局——防守反击）；ch4 生成关（5×5 交替先后手+AI 中等强度）
- 星级：错次口径（负局=1 错；平/胜不计）；救援=当前可制胜点/必堵点 breathe（**对战款豁免 miss 门控**——无方向级/答案级自然分层，14s 呆滞给点位即救援本义，审查 m1 裁决）；负局重开**换先手**（审查 M2：挫败兜底链「重下→换我先下」，连负交替换）
- 教学：watch=演示连四取胜一局快放；帮/独；`__gkDemoR`
- 钩子：`GK = { get currentLevel, get quiz(){ N(棋盘边), board[](0 空/1 玩家/2 兔子), turn(1|2), phase('play'|'win'|'lose'|'draw'), winline(四连线坐标或 null), step, miss }, tapCell(i), aiMove(), autoSolve() }`
- 语音：gk_tut_watch'看！连成四个子'/gk_tut_turn'你来下一局'/gk_hint'想想哪里能连四个'/gk_right'四个连上啦，你赢了'/gk_lose'兔子赢啦，再来一局'/gk_draw'平局，再来一局'；落子音=Web Audio

## §3 sudokunum 数独数字版（6×6 约束填充；点格选数款，不灰化）

**玩法**：每题=6×6 盘（2×3 宫），部分格预填，空 6-14 格。点空格→底部数字卡 1-6 选填；行/列/宫不重复。填错=格子摇头+零惩罚可改（点已填格=清除）。全对=celebrate+下一题。
- 题型（4 章）：ch1 6-8 空（行/列直接排除可解）；ch2 9-11 空（需列+宫联合）；ch3 12-14 空（宫排除必用+唯一候选链）；ch4 生成关（12-14 空随机验证唯一解）
- 星级：错次口径（填错=1 错）；救援=唯一候选格 breathe+该格数字卡 pulse（**答案级：miss≥2 才出**——b18 梯度定案：错 1 次仅闪「有唯一候选的格」方向级线索）
- 教学：watch=演示行排除→选数；帮/独；`__snDemoR`
- 钩子：`SN = { get currentLevel, get quiz(){ grid[](36 格：0 空/1-6 预填), given[](bool), sol[](36 格解), step, miss }, tapCell(i), tapNum(n), autoSolve() }`
- 语音：sn_tut_watch'看！每行每列不重复'/sn_tut_turn'你来填一填'/sn_hint'看看这一行少了谁'/sn_right'全部填对啦'/sn_wrong'这个数字不对哦'；数词=TTS 兜底（sn_n_ 不建）
